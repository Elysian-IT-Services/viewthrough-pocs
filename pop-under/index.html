Pop-under

Accepting consent opens a copy of this lander in a new tab — the one you keep looking at — and sends this tab to the affiliate link, so loads top-level in the tab behind you.

Attributes, and works in every browser. It never asks for window features, so fullscreen and in-app browsers can't break it. Cost: the operator tab lingers, because a script can only close a window it opened itself. 
Ready. Nothing has fired.

How it works

Six steps, all in the instant the reader clicks Accept:

  1. The Accept click is caught.
    mountConsentGate({ onConsent: popUnder })
  2. We check this reader hasn't already been counted, so a second click can't fire a second affiliate click.
    readDeferredClick()
  3. We build the address of a copy of this page — the same URL with ?resumed=1 added, so the copy knows it is the copy.
    new URL(location.href) · searchParams.set(RESUME_PARAM, '1')
  4. We open that copy in a new tab. New tabs come to the front, so this is what the reader is now looking at — our page, unchanged.
    window.open(resumeUrl, '_blank')
  5. We write down that the click has fired.
    recordDeferredClick('pop-under')
  6. We send the tab they just left to the operator. It is now the tab behind, so the operator loads out of sight while the reader carries on with us.
    location.replace(activeOperatorUrl())

Two things that matter: all of it has to happen on the click itself — wait even a moment and the browser treats the new tab as a popup and blocks it. And the last step replaces the page rather than adding to history, so the Back button never takes the reader into the operator's site.
