Opener isolation

This POC tests what a page you open in a new tab can do to the tab that opened it. It worked and the result is the one the standard promises: a plain target="_blank" link hands the new tab a live window.opener handle it can use to navigate this page somewhere else, and adding rel="noopener" sets that handle to null. That handle is also what the pop-under POCs need, so turning it off is not free.

How to test

  1. Press Open without noopener. The new tab reports that window.opener is live.
  2. Switch back to this tab. Expect it to have been navigated away to a page you did not ask for, which is the whole attack.
  3. Come back here with the browser's back button, then press Open with noopener. The new tab reports that window.opener is null.
  4. Switch back to this tab again. Expect it to be untouched, still showing this text.
