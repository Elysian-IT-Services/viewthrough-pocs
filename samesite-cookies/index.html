SameSite cookies

Our server sets the same cookie under each SameSite policy so you can see what the browser stores. These are same-site requests, so all three are accepted — the cross-site case is the one that breaks attribution.

Test it

  1. Application → Cookies → this origin. Delete tracking_id.
  2. Press each button and re-read the list: tracking_id is stored every time, with the SameSite column changing.
  3. None only stores because localhost counts as secure; on plain http it would be dropped.
