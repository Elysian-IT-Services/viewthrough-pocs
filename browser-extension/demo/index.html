VTA extension — demo lander

Stand-in for the real lander. Accept marketing consent, then click the banner. The page asks the installed extension to open the affiliate link as a real top-level navigation in a background tab — no iframe, no popup, no spoofing. The operator sees an ordinary first-party visit.

What only an extension can do: prove it worked. After the click it reads the real cookie jar, records the exact the operator's own script issued, and can replay that same value if the browser later drops it. The toolbar popup shows the recorded ID next to the live one — matching is the attribution proof. It also times the cookie: "Cookie after" is how many milliseconds the operator actually needed, which is the smallest close delay the pop-over can safely use.
Reach, bluntly: Chrome and Edge desktop only. Firefox needs manifest changes, Safari needs an Xcode app wrapper, iOS Safari is severely limited, and Meta's in-app browser supports no extensions at all. This traffic is paid Meta ads, so the extension is an add-on for desktop users — not a replacement for the click-through or the pop-under.
