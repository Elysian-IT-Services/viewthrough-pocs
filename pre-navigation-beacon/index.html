Pre-navigation beacon

Whether a tracking request can finish after the reader has already left. navigator.sendBeacon delivers it in the background, so the link never has to be delayed or faked.

Test it

  1. Network tab → tick Preserve log, or the record clears on navigation and you see nothing.
  2. Press Leave this page. The browser leaves immediately, with no pause.
  3. Come back and read the preserved log: a track-beacon request of type ping, status 204. The server terminal prints its body.
